# Public Scope

This repository is a public P00-P02 foundation release only.

Included:

- deterministic proof/control surfaces
- semantic-bedrock implementation surfaces
- bootstrap-boundary implementation surfaces
- fixtures, receipts, goldens, docs, tests, examples, and public reference outputs for P00-P02

Excluded:

- private roadmap/master instruction file
- future phase inventory beyond the public P00-P02 foundation
- private AI-agent prompts and Cursor/Codex control instructions
- commercial strategy and valuation notes
- unpublished P03+ work

Publication boundary:

- This repository may be used to demonstrate that the Lyra foundation exists as code and artifacts.
- It should not be presented as the complete Lyra OS.
- It should not be presented as P03 parser/source-loader work.
